# Offre Bac — HTML / CSS / JavaScript

نسخة واجهة أمامية مستوحاة من الموقع المنشور https://offrebac.netlify.app/، مبنية بثلاثة ملفات منفصلة:
- `index.html` — بنية الصفحة والمحتوى.
- `style.css` — التصميم المتجاوب للأجهزة المختلفة.
- `script.js` — القائمة المتنقلة، استمارة واتساب، وتجربة الدالة التفاعلية.

## التشغيل
افتح `index.html` مباشرة في المتصفح. الخط Tajawal وDM Sans يتم تحميلهما من Google Fonts عند توفر الإنترنت؛ الموقع يعمل كذلك بخطوط بديلة.

## ملاحظات
- هذا إعادة بناء للواجهة والوظائف الظاهرة اعتماداً على الصفحة العامة، وليس استخراجاً حرفياً لملفات المصدر الأصلية.
- رقم واتساب مضبوط على `212663271459` حسب معلومات التواصل الظاهرة في الموقع.
- التسجيل يفتح رسالة جاهزة في واتساب ولا يرسلها تلقائياً؛ يجب على المستخدم الضغط على إرسال.
- لا توجد قاعدة بيانات أو معالجة خلفية. التحقق من الاستمارة يتم في المتصفح فقط.
